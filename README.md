# Project — быстрая доска объявлений Молдовы (рабочее название)

Лёгкая и быстрая площадка объявлений (RU / RO) с ИИ-помощником поиска.
Сейчас это **фронтенд-прототип**: работает в браузере без сервера, объявления — демонстрационные.

## Возможности

**Поиск и каталог**
- 16 категорий и ~80 подкатегорий, меню «Все категории»
- Расширенный поиск по параметрам раздела: марка, год, пробег, топливо, КПП (авто); комнаты, площадь, этаж, район (недвижимость); процессор, видеокарта, RAM, SSD (ПК) и др.
- Фильтры: цена (лей / €), регион, состояние, «только с фото», «частные», «Хорошая цена», «С доставкой», «Проверенные продавцы»
- Сортировка: новые, дешёвые, дорогие, самые выгодные, популярные
- Вид: плитка, список, **карта Молдовы** с количеством объявлений по городам
- Метка **«Хорошая цена»** — цена ниже средней по похожим объявлениям

**ИИ-помощник** («Спросить ИИ»)
- Запрос обычным языком: «найди лучший ПК за 15 000 лей»
- ИИ ищет только по объявлениям сайта (инструмент `search_ads`), сравнивает характеристики и цену к рынку, показывает 1–3 лучших варианта
- Без доступа к ИИ работает запасной локальный подбор (понимает бюджет, валюту, тип товара, «автомат», комнаты, район)

**Маркетплейс**
- Профиль продавца: рейтинг, отзывы, распределение оценок, «Документы проверены», скорость ответа, все объявления продавца
- Встроенный **мессенджер** с быстрыми ответами («Ещё продаётся?», «Торг уместен?»…)
- **Доставка с безопасной сделкой**: пункт выдачи / курьер, расчёт стоимости, заказ и отслеживание статуса
- **Личный кабинет**: мои объявления (поднять / снять), заказы, сохранённые поиски, просмотренные
- **Сохранённые поиски** с подсчётом новых объявлений
- **Продвижение** при подаче: выделение цветом, ТОП, Турбо
- «Рекомендации для вас» и «Вы недавно смотрели» на главной
- Похожие объявления и другие объявления продавца в карточке
- Поделиться ссылкой (`#ad-123`), пожаловаться
- Избранное

**Интерфейс**
- Адаптив: телефоны (нижнее меню, фильтры шторкой), планшеты, ноутбуки, Full HD / 2K / 4K
- Светлые читаемые поля даже при тёмной теме системы
- Без тяжёлых библиотек: чистый HTML/CSS/JS, иконки встроены

## Запуск

Сервер не нужен — откройте `index.html` в браузере.
Или локальный сервер:

```bash
python3 -m http.server 8080
# открыть http://localhost:8080
```

### GitHub Pages
Settings → Pages → Branch: `main`, папка `/ (root)` → сайт будет на `https://<логин>.github.io/<репозиторий>/`.

## Структура

```
index.html               разметка страницы
assets/css/styles.css    все стили (адаптив внизу файла)
assets/js/
  icons.js               иконки Lucide (генерируется tools/build_icons.py)
  illustrations.js       собственные векторные иллюстрации товаров для демо-объявлений
  catalog.js             регионы, категории, подкатегории, атрибуты фильтров
  demo-data.js           демо-объявления и продавцы (заменить на API)
  i18n.js                переводы RU / RO
  app.js                 состояние, движок поиска query(), отрисовка, окна, подача объявления
  ai.js                  ИИ-помощник и запасной локальный подбор
  features.js            продавцы, чат, доставка, кабинет, сохранённые поиски, карта, рекомендации
  events.js              обработчики событий
  main.js                запуск
tools/build_icons.py     сборка icons.js из lucide-static
```

Добавили иконку `data-lucide="..."`? Пересоберите:
```bash
npm i lucide-static && python3 tools/build_icons.py
```

## Что сейчас демо (нужен сервер)

| Функция | Сейчас | Для запуска |
|---|---|---|
| Объявления | генерируются в `demo-data.js` | база данных + API |
| Свои объявления, чаты, заказы, избранное | `localStorage` браузера | аккаунты и сервер |
| Вход | заглушка | вход по SMS-коду |
| Ответы продавца в чате | автоответчик | реальный мессенджер (WebSocket) |
| Оплата доставки и продвижения | не списывается | платёжный провайдер |
| ИИ-поиск | через Claude в среде claude.ai | Claude API на своём сервере (ключ хранить только на сервере) |
| Фото | хранятся в браузере | облачное хранилище + сжатие |

## Дорожная карта
